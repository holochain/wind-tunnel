Unyt Chain Transaction

↑ Back to index

Tests Unyt chain transaction system performance with credit ledger and smart agreement primitives. The scenario has three roles:

  • initiate: Progenitor agent that initializes the network with system templates, global configuration, and foundational smart agreements
  • spend: Transaction agents that accept incoming commitments and create spend transactions distributed among participants
  • smart_agreements: Smart agreement agents that collect RAVEs, execute agreements, and create parked link spending transactions
